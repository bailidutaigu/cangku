# 学习通 / 超星 网课助手 Pro

> 一个跑在浏览器里的 Tampermonkey 用户脚本：自动播放、锁定倍速、跨 iframe 自动下一节、调用大模型做题并自动提交、文档/PPT 自动翻页。

## 这是什么

学习通的课程页是「顶层壳 + 一堆 iframe」的结构：视频在 `ananas/modules/video` 里，作业在 `mooc/ans/work` 里，而左侧章节目录和「下一节」按钮又在另一层。

这个脚本解决的就是这种结构带来的所有麻烦——它在**每一个** frame 里都注入一份，通过 `postMessage` 互相通信，谁那儿有按钮谁点，谁那儿有视频谁播。答题部分把题目抓下来丢给任意 OpenAI 兼容接口，拿到答案后模拟真实点击序列落盘，再自动提交。

不是录屏挂机器，也不是改服务端数据。它做的都是「一个人坐在电脑前也能做的操作」，只是做得更快、更不知疲倦。

## 功能

| 模块           | 具体行为                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------- |
| **视频**       | 自动 `play()`；静音；倍速 1–16 任意值，劫持 `HTMLMediaElement.prototype.playbackRate` 的 setter，播放器想改回 1x 会被立刻掰回来 |
| **后台保活**     | 伪造 `document.hidden` / `visibilityState` / `hasFocus()`，拦掉 `visibilitychange`，切标签页不暂停              |
| **自动下一节**    | 5 个策略轮换（弹窗按钮 → 分页控件 → 左侧目录树 → 文本匹配 → 「下一页」），点完 2 秒校验 URL/DOM 是否真的变了，没变自动换下一个                       |
| **跨 iframe** | 视频结束 → `postMessage` 广播 → 顶层找不到就逐层向下转发（最多 3 跳），谁有按钮谁点                                              |
| **AI 答题**    | 抓题干与选项 → 拼 prompt → 并发调模型（默认 3 路）→ 解析字母 → 模拟点击                                                     |
| **题型覆盖**     | 单选 / 多选 / 判断 / 填空（多空用 `\|\|\|` 分隔）/ 简答                                                             |
| **通用解析**     | 超星那套 class 匹配不上时，按「成组的 radio/checkbox」自动配对题干与选项，任何客观题页面都能答                                         |
| **自动提交**     | 先答完再封页（防止轮询重跑把选项点掉）→ 找提交按钮（跨所有同源文档）→ 点击 → 10 秒窗口内自动点掉确认框（确认按钮文案是「提交」也能认）                           |
| **文档翻页**     | 找到最大滚动容器按 85% 屏高下滚，到底点翻页按钮，再不行发 `PageDown`                                                         |
| **答案缓存**     | 题型+题干+选项哈希存 localStorage，同一道题只问一次，重刷不烧额度                                                           |

## 安装

### 1. 装 Tampermonkey

| 浏览器           | 地址                                                                                                    |
| ------------- | ----------------------------------------------------------------------------------------------------- |
| Chrome / Edge | [Chrome 应用商店](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| Firefox       | [Firefox 附加组件](https://addons.mozilla.org/firefox/addon/tampermonkey/)                                |

### 2. 装脚本

**一键安装**：

```
https://raw.githubusercontent.com/bailidutaigu/cangku/main/cx-helper.user.js
```

浏览器打开这个链接，Tampermonkey 会弹出安装页，点「安装」。

或者手动：Tampermonkey 面板 → `+` → 粘贴 `cx-helper.user.js` 全文 → `Ctrl+S`。

### 3. 配 API

打开任意课程页，右上角出现面板，填三个框：

| 字段      | 示例                                                                                                                                                         |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| API 地址  | `https://api.deepseek.com/v1` · `https://dashscope.aliyuncs.com/compatible-mode/v1` · `https://api.openai.com/v1` · `http://127.0.0.1:11434/v1`（本地 Ollama） |
| API Key | `sk-...`（本地模型随便填）                                                                                                                                          |
| 模型名     | `deepseek-chat` · `qwen-plus` · `gpt-4o-mini` · `qwen2.5:7b`                                                                                               |

点面板上的 **诊断**，看到 `API=set` 就通了。

> 脚本本身不含任何 Key，配置存在你浏览器的 Tampermonkey 存储里。

## 使用

打开课程页后一切自动。面板上还有几个手动入口：

| 按钮   | 作用                                         |
| ---- | ------------------------------------------ |
| 立即答题 | 手动触发一轮答题（会重置失败计数和封页状态）                     |
| 下一节  | 手动翻页；本层没有按钮时广播给其它 frame                    |
| 提交   | 手动触发提交                                     |
| 扫描   | 把当前题目的选项 HTML 复制到剪贴板（提 issue 时附上这个）        |
| 全量诊断 | 列出所有可访问 frame 的 URL、题目数、含「提交/交卷/保存」的按钮及可见性 |

## 工作原理

```
┌─────────────────────────────────────────────┐
│ 顶层 frame                                    │
│  ├─ 面板 UI（配置 / 日志 / 手动入口）           │
│  ├─ postMessage 总线 ──┬──► 视频 iframe         │
│  │  (next/cfg/solve/   │     ├─ 播放 / 倍速     │
│  │   scan/submit/      │     └─ ended → 广播    │
│  │   confirm)          ├──► 作业 iframe         │
│  └─ 逐层向下转发(≤3跳)   │     ├─ 抓题 → 调模型  │
│                        │     └─ 落答案 → 提交  │
└─────────────────────────────────────────────┘
```

几个关键设计：

**配置要广播，不能只改本地。** 面板在顶层，视频在子层。顶层改的 `cfg` 子层收不到，所以任何配置变更都会 `pushCmd('cfg')` 下发，子层 `Object.assign(cfg, remote)` 后立即 `applyRateNow()`。子层启动 1.2 秒后还会主动 `getcfg` 拉一次，解决「先开页面后填 Key」。

**答题必须幂等。** 切换式选项（点一下选中，再点取消）经不起重复点击。主循环每 400ms 一轮，所以每题先查 `questionAnswered(q)`，页面上已经选好就跳过；全部答完写入 `state.done[href]` 封页，轮询不再重跑。

**点击要验，不能假报成功。** 每次点击前记录选项指纹（class + 子节点数 + innerHTML 长度 + checked），点完比对，变了才算页面接受。8 级递进：`input` → `label` → 图标 → `li` → 3 层祖先 → `elementFromPoint` → 内联 `onclick` → 强制 `checked`。

**扫描要排除自己。** 面板上就有「下一节」「提交」按钮，文本匹配会命中它们，导致脚本点自己、页面毫无反应。所以 `isVisible()` 内含 `inOwnUI()`，`#cxh-panel` / `#cxh-badge` 内的一切元素对所有扫描一律不可见。

**提交按钮可能不在这一层。** 提交时会递归遍历所有同源 frame（`safeDocs()`），在整棵文档树里找按钮；点击事件用元素自己所在 realm 的构造函数来造，跨文档 `dispatchEvent` 才不会抛 `TypeError`。

## 常见问题

<details>
<summary><b>面板不出现</b></summary>

Tampermonkey 图标上是否有数字角标？没有的话说明脚本没匹配到当前页面。检查 `@match` 是否覆盖你访问的域名。

</details>

<details>
<summary><b>能点选项但不提交</b></summary>

看日志顺序：`作答结束 x/y` → `点提交：...` → `点确认：...`。哪一步断了就对症：

- `作答结束 0/y`：一题都没判定成功，点「扫描」把结果发 issue
- `找不到提交按钮`：日志会列出所有候选，附 HTML 发 issue
- `点了提交但页面没反应`：确认框可能在跨域 frame 里

  </details>

<details>
<summary><b>倍速改了没效果</b></summary>

只有 `<video>` 元素能被改倍速。如果播放器是 canvas 自绘或加密流，改不了。另外确认「强制锁倍速」开关是开的。

</details>

<details>
<summary><b>视频不自动播放</b></summary>

Chrome 的自动播放策略要求静音才能自动播，脚本默认静音，所以一般没问题。若仍不动，点一下播放器的播放按钮即可，之后脚本接管。

</details>

<details>
<summary><b>验证码 / 滑块 / 拍照签到</b></summary>

这类是服务端一次性下发的校验，脚本不处理，弹出手动过，过完继续。

</details>

<details>
<summary><b>想让别的站点也能用</b></summary>

视频模块是通用的，加一行 `@match` 即可。答题的 DOM 不同就改两处：`OPT_SEL`（选项 li）和 `SUBMIT_SEL`（提交按钮）；题干解析、题型判定、答案落盘逻辑不用动。

</details>

## 已知限制

- 只支持 `<video>` 元素，canvas 自绘播放器改不了倍速
- 确认框若渲染在**跨域且未注入脚本**的 frame 里，点不到（脚本无法跨域操作 DOM）
- 主观题（简答/论述）的答案质量取决于模型水平，不等于老师标准答案
- 「秒过」功能默认关闭：它改写客户端上报的 `playingTime`，服务端有节奏校验时可能被判异常
